## User Scenarios & Testing *(mandatory)*

### User Story 1 - 选择路线并获得起点定位 (Priority: P1)

学习者首次进入系统，从三条学习路线中选择一条：**纯理论研究**（马恩奠基→辩证法与认识论→体系化→政治经济学→当代理论判据）、**组织革命**（列宁建党夺权→斯大林一国建设→毛泽东建党与群众路线→周恩来组织工作三部曲）、**建设社会主义国家**（《哥达纲领批判》→《论人民民主专政》→《论十大关系》→《关于正确处理人民内部矛盾的问题》→社会主义政治经济学）。做完一组 8–15 题的**定位测**后，系统给出"从哪一章/哪一节开始"的建议，而不是默认从第一章读起。

**Why this priority**: 没有起点定位，三条路线就只是三份书单；学习者会在已懂的章节上浪费时间，或从过难处开始而放弃。定位测 + 起点建议是"路线"变成"教学"的第一步，且不依赖掌握度历史数据即可交付。

**Independent Test**: 新用户选择"组织革命"，完成定位测（答错《怎么办？》相关 2 题、答对《国家与革命》相关 3 题），系统建议起点为《怎么办？》第二章并说明理由（前置依赖未满足 + 该节点解锁 4 个下游节点）。

**Acceptance Scenarios**:

1. **Given** 学习者是全新用户，**When** 进入学习中心，**Then** 系统展示三条路线的目标描述、预计投入、首站推荐，且可查看每条路线的阶段-模块全貌后再选择
2. **Given** 学习者选择"纯理论研究"，**When** 完成 12 题定位测，**Then** 系统在 3 分钟内给出起点章节、起点理由、以及"已掌握可直接跳过"的章节清单
3. **Given** 学习者对定位结果不认同，**When** 点击"我要从更早处开始"，**Then** 系统接受人工指定起点并保留定位测结果作为学情证据（不删除、不降权为零）
4. **Given** 学习者在"组织革命"路线学习两周，**When** 切换到"纯理论研究"，**Then** 已产生的知识状态与证据完整保留，仅推荐、必读集与题型配比按新路线重算

### User Story 2 - 章节学完后的掌握度诊断与测试 (Priority: P1)

学习者读完一章（如《提纲》第 1–3 条），触发掌握度诊断：系统按知识点出题（概念辨析/文本定位/逻辑推演/错误诊断/溯源/迁移六类），判分后给出每个知识点的五级状态（未接触/初学/熟悉/精通/贯通）、**错误类型标签**（机械唯物/唯心/概念层次混淆/术语混用/立场偏离/记忆性失误），以及三条可执行的下一步动作。

**Why this priority**: 这是"读完"与"读懂"的分界线，也是产品区别于电子书的核心。它与 User Story 1 同属最小闭环，缺一不可。

**Independent Test**: 学习者学完《提纲》第 1–3 条后触发诊断，在"实践"概念辨析题误选"日常行为"，系统标记"实践"为初学、错误类型为"术语混用"，并推荐回到第 1 条解析层"实践≠道德践履"段落 + 2 道专项题。

**Acceptance Scenarios**:

1. **Given** 学习者完成一章全部小节阅读，**When** 触发诊断，**Then** 系统生成覆盖该章核心知识点的六类题型（其中至少 1 道溯源题、1 道迁移题），题量随章节权重在 8–20 题之间
2. **Given** 学习者答错一道错误诊断题，**When** 系统判分，**Then** 输出错误类型标签 + 正确项与所选干扰项的差异说明 + 对应原文锚点链接
3. **Given** 学习者在同一知识点连续 3 次答错，**When** 诊断结束，**Then** 该知识点进入"补丁队列"，系统插入定向段落 + 专项题，且不在仪表盘标为已掌握
4. **Given** 学习者全部答对且置信度足够，**When** 诊断结束，**Then** 知识点状态升级，并解锁该节点下游的推荐（但不强制锁定未达标章节）
5. **Given** 判分涉及主观迁移题，**When** 系统无法高置信判定，**Then** 显示"待确认"并要求学习者自评或提交专家复核，不计入掌握度

### User Story 3 - 对话中学习并隐式更新学情 (Priority: P2)

学习者在阅读器里选中文本与 AI 会话（释义/追问/辩难/关联/应试）。会话结束后，系统从对话中抽取**学习证据**（是否用对术语、是否混淆概念层次、辩难防守质量、是否绕开追问），写入学情，并在回合结束时给出一张"本节小结卡"。

**Why this priority**: 对话是最高频的学习行为，不利用它，学情只能靠低频测试，画像会失真；但它属于"增强"，缺了不影响 US1/US2 闭环。

**Independent Test**: 学习者在"追问"模式回答"实践就是人做事情"，AI 指出其落入"日常行为"近义词陷阱；小结卡显示"已理解：实践的对象性；待纠正：实践≠日常行为"，且该证据以低置信度写入"实践"节点，等待测试确认。

**Acceptance Scenarios**:

1. **Given** 学习者在会话中正确使用"对象性活动"解释实践，**When** 会话结束，**Then** 系统生成证据（来源=对话，置信度 ≤0.6）并更新该节点置信度，不直接升到"熟悉"以上
2. **Given** 对话证据与显式测试冲突，**When** 合并学情，**Then** 以显式测试为准，冲突记录保留供复盘
3. **Given** 系统判定学习者已掌握某概念，**When** 展示学情卡，**Then** 提供"不对，我还没掌握"的纠正入口，纠正后该证据标记为已撤销并回退状态
4. **Given** 会话进行 5 轮以上，**When** 学习者点击"结束本节"，**Then** 输出小结卡：答对点 / 混淆点 / 建议下一问，三者各不超过 3 条
5. **Given** AI 服务不可用，**When** 学习者在阅读器中批注，**Then** 阅读与批注正常，证据暂存本地并在恢复后补写，不打断学习

### User Story 4 - 推荐下一步与欠账补救 (Priority: P2)

系统在任意时刻给出"现在最该学什么"：优先前置依赖已满足、且能解锁最多下游的节点；同时列出"欠账清单"（学过但未达标的节点）与对应补丁。

**Why this priority**: 推荐是把学情转成行动的关键一步；没有它，诊断结果只是报告。

**Independent Test**: 学习者在"否定之否定"上连续失败，系统不推荐继续读第 4 章，而是推荐"《哲学笔记》摘要指定段落 + 3 道专项题"，并说明该节点解锁 5 个下游节点。

**Acceptance Scenarios**:

1. **Given** 学习者打开学习中心，**When** 系统计算推荐，**Then** 输出 1 个主推荐 + 最多 2 个备选，每条含章节、预计耗时、推荐理由（依赖/杠杆/欠账/到期复习四类之一）
2. **Given** 学习者有 3 个欠账节点，**When** 进入推荐，**Then** 欠账节点排在"新内容"之前，并可一键开始补丁
3. **Given** 学习者忽略推荐连续 3 次，**When** 再次进入，**Then** 系统改用更小的学习单元（单节/单概念）并询问偏好，不重复同一推荐
4. **Given** 学习者的路线内容尚未上线（如建国路线的《论十大关系》未入库），**When** 推荐计算命中该节点，**Then** 明确提示"该章尚未开放"并推荐同路线内可替代节点

### User Story 5 - 三档总结反馈与学习仪表盘 (Priority: P3)

学习者在回合级（会话小结卡）、章节级（诊断报告）、周期级（每周学情周报）三个节奏收到反馈；仪表盘展示能力雷达（唯物论/辩证法/认识论/史观/政经）、学习热力图、薄弱点 Top5、欠账清单。

**Why this priority**: 提升长期留存与自我调节能力，但依赖 US2/US3 已产生数据。

**Independent Test**: 学习一周后打开周报，看到"本周新增掌握 7 个节点、欠账 3 个、复习到期 12 张、辩证法维度 +8%"，且每条薄弱点都带一个可点击的下一步。

**Acceptance Scenarios**:

1. **Given** 学习者完成一章，**When** 诊断结束，**Then** 生成章节报告：掌握度分布、错误类型分布、薄弱点 Top3、下一步动作，且每项动作可直接跳转
2. **Given** 一周内有学习行为，**When** 周一（或用户设定的周期）到达，**Then** 生成周报：掌握增量、能力雷达变化、欠账、复习到期、路线偏离提醒
3. **Given** 学习者在仪表盘看到"辩证法薄弱"，**When** 点击该维度，**Then** 下钻到具体节点与证据（哪次测试/哪次对话导致该判断），不只给结论
4. **Given** 学习者连续 7 天无学习行为，**When** 系统检测到，**Then** 发送一次温和提醒（含最短可完成的动作），不做高频推送

### User Story 6 - 间隔重复与复习队列 (Priority: P3)

系统按间隔重复算法生成每日复习队列（概念卡、曾经的错题、苏格拉底问题），到期项进入推荐。

**Why this priority**: 抗遗忘决定三个月后的留存，但需要先有掌握度数据。

**Independent Test**: 学习者 3 天前学过"市民社会"且当时为初学，今天打开系统看到该概念卡在复习队列首位，完成后状态置信度提升。

**Acceptance Scenarios**:

1. **Given** 某知识点上次复习为 3 天前且评级为"困难"，**When** 今日队列生成，**Then** 该节点排在队列前部
2. **Given** 复习连续 3 次评级"容易"，**When** 计算下次间隔，**Then** 间隔按算法延长且上限受"章节诊断未通过则强制回炉"约束
3. **Given** 学习者跳过复习 5 次，**When** 再次进入，**Then** 队列不超过 20 项并允许"只做 5 项"的降级模式

### User Story 7 - 内容与题目入库审核 (Priority: P4)

内容编辑把路线、章节、知识点、题目、评分要点录入为结构化配置；AI 生成或辅助生成的题目必须经离线校验（立场/事实/术语）与人工抽检后才能进入正式题库。

**Why this priority**: 没有审核，错误题目会直接教错人；但它可以先用人工录入的少量题目支撑 P1，故排后。

**Independent Test**: 编辑提交一道 AI 生成的溯源题，离线校验标记"选项 C 表述含修正主义倾向"，题目被拦截且不可发布，编辑修正后通过并进入抽检队列。

**Acceptance Scenarios**:

1. **Given** 编辑导入一份路线配置文件，**When** 校验，**Then** 系统报告孤儿知识点（无题目）、断链前置依赖、未映射到任何路线的节点
2. **Given** AI 生成题目进入草稿区，**When** 离线校验运行，**Then** 立场/事实/术语三类校验全通过才可提交人工审核
3. **Given** 题目通过审核上线，**When** 学习者作答，**Then** 题目版本与该题目评分要点可追溯到审核记录

## Edge Cases

- **路线中途切换**：已掌握节点保留，新路线的必读集重算；若新路线要求的前置节点未掌握，插入"最小补丁"而非整章重读
- **同一知识点跨路线冲突**：概念定义共用一份权威定义；路线只影响权重与题型，不允许出现两套定义
- **定位测题库不足**：某路线定位题少于 8 题时，降级为"章节抽样阅读 + 5 题快测"，并提示定位精度较低
- **AI 判分不可用**：客观题照常判分；主观题进入待确认队列，掌握度更新暂缓并显式告知
- **学习者答非所问**：连续 2 次答非所问时，系统给出更小的提示（术语提示/原文锚点），不计为错误
- **重复作答刷分**：同一题目在 7 天内重复出现时，不计入掌握度升级（只作复习记录）
- **掌握度虚高**：对话证据把节点推到"熟悉"后，若后续测试失败，自动回退一级并记录"证据冲突"
- **内容未上线**：推荐命中未上线章节时，给替代节点 + 上线提醒，不产生死链
- **离线使用**：断网时阅读、批注、本地题目可作答，证据排队同步；冲突以服务端显式测试为准
- **立场档位与内容冲突**：路线若被配置为"批判对照"档位，而节点内容只有正统档位版本，系统拒绝开启该档位而不是降级为无标注对照
- **未成年人/机构模式**：可关闭"迁移题"的开放作答与周报推送

## Requirements *(mandatory)*

### Functional Requirements

**路线与内容结构**

- **FR-101**: 系统 MUST 提供三条内置学习路线（纯理论研究 / 组织革命 / 建设社会主义国家），每条路线由阶段→模块→节点三级结构组成，节点 MUST 可映射到既有概念与原著分块标识
- **FR-102**: 路线 MUST NOT 携带独立的概念定义副本；同一概念在所有路线中共用一份权威定义与术语红线
- **FR-103**: 每条路线 MUST 声明：必读节点集、概念权重、题型配比、默认起点候选、预计投入时长
- **FR-104**: 学习者 MUST 可在任意时刻切换路线，切换后已产生的证据与知识状态 MUST 完整保留
- **FR-105**: 系统 MUST 支持一个节点被多条路线引用（共享而非复制），并支持节点级的前置依赖声明
- **FR-106**: 系统 MUST 在路线配置导入时校验：孤儿节点（无题目/无内容）、断链依赖、未映射节点，并输出可读报告

**起点定位与推荐**

- **FR-107**: 新用户 MUST 可通过定位测（8–15 题，覆盖该路线各阶段抽样）获得起点建议；建议 MUST 包含起点章节、理由、可跳过清单
- **FR-108**: 学习者 MUST 可覆盖系统起点建议，人工起点 MUST 被记录为证据而非被丢弃
- **FR-109**: 推荐 MUST 按"前置依赖已满足的待学节点"（前沿集合）计算，排序因子 MUST 包含杠杆值（该节点解锁的下游节点数）、欠账程度、复习到期、学习者近期偏好
- **FR-110**: 每次推荐 MUST 输出 1 主 + ≤2 备选，并给出四类理由之一（依赖/杠杆/欠账/到期复习）与预计耗时
- **FR-111**: 推荐 MUST NOT 硬性锁定未达标章节；未达标节点 MUST 以"欠账"形式持续出现在推荐与仪表盘中
- **FR-112**: 连续忽略推荐 3 次时，系统 MUST 缩小推荐单元（章→节→单概念）并询问偏好

**学情与证据**

- **FR-113**: 系统 MUST 以"证据事件"作为学情唯一写入源，证据 MUST 记录来源（测试/对话/费曼/阅读/人工指定）、时间、置信度、可撤销标记
- **FR-114**: 每个知识点的状态 MUST 包含五级（未接触/初学/熟悉/精通/贯通）与置信度，并记录最近一次更新来源
- **FR-115**: 显式测试证据 MUST 覆盖对话证据；冲突 MUST 保留双份记录并标注"已按测试为准"
- **FR-116**: 对话证据 MUST 由会话后处理抽取，且 MUST 只在置信度达到阈值时更新置信度，不得直接跨越两个等级
- **FR-117**: 学习者 MUST 可对任何自动判定提出纠正，纠正 MUST 撤销对应证据并回退状态
- **FR-118**: 每条自动判定 MUST 可下钻到原始证据（哪道题、哪轮对话、哪段原文）

**测试**

- **FR-119**: 系统 MUST 提供六类题型：概念辨析、文本定位、逻辑推演、错误诊断、溯源（判定观点/流派归属）、迁移（用原理分析新现象）
- **FR-120**: 判分 MUST 输出错误类型标签（机械唯物/唯心/概念层次混淆/术语混用/立场偏离/记忆性失误）并给出干扰项差异说明
- **FR-121**: 客观题 MUST 自动判分；主观题（迁移题）MUST 采用评分要点判分，低置信时进入"待确认"而非直接判错
- **FR-122**: 题量 MUST 按章节权重自适应（8–20 题），并能根据连续对错调整后续题目难度
- **FR-123**: 同一题目 7 天内重复出现 MUST 不计入掌握度升级
- **FR-124**: AI 生成或辅助生成的题目 MUST 通过立场/事实/术语三类离线校验，并进入人工抽检队列后才可发布
- **FR-125**: 每道题 MUST 关联至少一个知识点与一个原文锚点（除综合迁移题必须关联≥2 个）

**反馈**

- **FR-126**: 系统 MUST 提供三档反馈：回合级小结卡、章节级诊断报告、周期级周报
- **FR-127**: 每条反馈中的"下一步" MUST 是可执行动作（跳转到具体章节/段落/题目），MUST NOT 只给"你比较薄弱"式结论
- **FR-128**: 章节报告 MUST 包含掌握度分布、错误类型分布、薄弱点 Top3、下一步动作
- **FR-129**: 周报 MUST 包含掌握增量、能力雷达变化、欠账、复习到期、路线偏离提醒
- **FR-130**: 学习者 MUST 可关闭周报推送与提醒频率；系统 MUST NOT 高频推送（7 天无学习行为时最多 1 次提醒）

**仪表盘与复习**

- **FR-131**: 仪表盘 MUST 展示能力雷达（唯物论/辩证法/认识论/史观/政经）、热力图、薄弱点 Top5、欠账清单，且各维度 MUST 可下钻到节点与证据
- **FR-132**: 复习队列 MUST 基于间隔重复算法生成，并 MUST 受"章节诊断未通过则强制回炉"约束
- **FR-133**: 复习队列 MUST 支持降级模式（"只做 5 项"），且单日队列不超过 20 项

**审核与安全**

- **FR-134**: 路线配置、题目、评分要点 MUST 支持版本化，且题目上线 MUST 可追溯到审核记录
- **FR-135**: 所有 AI 输出的题目、解析、批改与反馈 MUST 经过既有防偏离校验（`specs/001` FR-005/FR-006/FR-007）；校验失败时 MUST 拒绝发布/展示，而非降级为未校验内容

### Key Entities *(include if feature involves data)*

- **LearningRoute（学习路线）**：路线标识、名称、目标描述、阶段序列、默认起点候选、题型配比、概念权重、立场档位
- **RouteStage / RouteModule（阶段/模块）**：所属路线、顺序、进入条件（软）、关联原著与章节范围、预计时长
- **KnowledgeNode（知识节点）**：节点标识、所属概念、前置依赖、原文锚点、题型权重、杠杆值（计算得出）、内容上线状态
- **EvidenceEvent（证据事件）**：学习者、来源类型、目标节点、结果（正确/部分/错误/质量分）、错误类型标签、置信度、时间、撤销标记
- **KnowledgeState（知识状态）**：学习者×节点、五级状态、置信度、最近证据、冲突标记
- **QuizItem（题目）**：题型、知识点、原文锚点、选项、正确答案、评分要点、难度、版本、审核状态
- **QuizAttempt（作答记录）**：题目、学习者、作答、判分结果、错误类型、用时、是否计入掌握度
- **LearningPlan（学习计划）**：路线、人工指定起点、当前推荐、欠账清单快照、周期设置
- **FeedbackReport（反馈报告）**：级别（回合/章节/周期）、关联对象、内容、生成的下一步动作、已读状态
- **ReviewSchedule（复习计划）**：节点、上次评级、下次到期、连续评级序列

> 实体字段与约束见 `data-model.md`；接口见 `contracts/`。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-101**: 新用户从选择路线到拿到起点建议，全程 ≤ 5 分钟（含定位测），其中系统计算 ≤ 3 秒
- **SC-102**: 新用户中 ≥ 80% 接受系统起点建议或仅做一次性微调（不整体回退到第一章）
- **SC-103**: 章节诊断从触发到出报告 ≤ 10 秒（不含主观题人工复核）
- **SC-104**: 系统标记为"熟悉"及以上的节点，在 14 天内后续测试中的正确率 ≥ 80%（掌握度校准）
- **SC-105**: 自动判定的纠正率（学习者点击"判定有误"）≤ 10%
- **SC-106**: 每条反馈中"可执行下一步"覆盖率 100%（人工抽检 50 条，无纯结论型反馈）
- **SC-107**: 推荐被采纳率（点击开始推荐内容）≥ 60%，且"连续忽略 3 次"发生率 ≤ 15%
- **SC-108**: 三条路线各自**首个已开放模块**的内容完整率 100%（无孤儿节点、无断链、必读节点每题有锚点）；其余模块允许 `planned` 占位但仍需通过导入校验
- **SC-109**: 上线题目的立场/事实错误率 = 0（离线校验拦截 + 人工抽检 200 题）
- **SC-110**: 错误类型标签人工抽检准确率 ≥ 85%
- **SC-111**: 复习到期项 7 日内完成率 ≥ 50%
- **SC-112**: 学习 4 周后学习者对"系统知道我的薄弱点"的认同度 ≥ 4/5（问卷，样本 ≥ 30）

## Assumptions

- 阅读器、五模式会话、防偏离三重机制、溯源卡片已由 `specs/001` 交付，本规格只做**增量**，不重建
- 首条完整验证路线为《提纲》11 条 + 周边节点（纯理论研究路线第一、二阶段），其余路线先落"骨架 + 第一模块"，再逐章补内容
- 三条路线共享一套知识图谱；路线是"视角/权重滤镜"，不是三套课程（避免内容量×3）
- 掌握度更新采用轻量贝叶斯式估计，不引入需要大量标注数据的深度知识追踪模型（数据量不足时不可靠）
- 题目以"人工编写 + AI 辅助生成、AI 校验 + 人工抽检"为主，不承诺全自动量产
- 单用户单设备为主，跨设备同步以服务端为权威
- 学习者为成人自学者与高校学生，无未成年人合规特例（机构模式仅提供开关）
- 时长估计基于章节字数与题目数量线性估算，不承诺精确

## Clarifications

### Session 2026-07-18

以下三项为影响范围的关键决策，按"最佳方案"采取默认值；如与预期不符，请在 `/speckit-implement` 前提出并可一次性修改：

1. **路线 = 立场档位吗？** → **是，但档位是路线内的显式开关，默认"正统"。**
   依据：`路径.txt` 含大量托洛茨基对照与"生态马/分析马/法兰克福"判据，与 `specs/001` "第 6 阶段批判对象、不得中立对照"直接冲突。因此路线本身不改变立场，只由"正统 / 批判对照"档位控制；`批判对照` 档位下参考文本必须带批判标记，且沿用 `specs/001` FR-006 的标记豁免机制。无对应档位内容的节点拒绝开启该档位。

2. **未达标的节点是否锁定后续章节？** → **不锁定（软门禁）。**
   依据：`specs/001` 原设计为"掌握度 <80% 拒绝解锁"，对自学者挫伤大。本规格改为"允许前进 + 欠账记账 + 补丁优先"，硬门禁仅保留给未来"考试路线"。

3. **三条路线是否互斥（同时只能选一条）？** → **主路线单一 + 允许跨路线取节点。**
   依据：同时追三条路线会导致学习碎片化；但"组织革命"学习者可能需要《矛盾论》，因此允许在推荐中引入其他路线的节点，并标注来源路线。

## Non-Functional Requirements

> 与 `specs/001` NFR 编号不重叠；`specs/001` 的 NFR-021/022/023/024/025（降级、熔断、fail-safe、离线、可用性）对本规格同样适用。

- **NFR-101**: 定位测、章节诊断、推荐计算在常见网络条件下 MUST 在 10 秒内返回（不含 LLM 主观题判分）
- **NFR-102**: 学情与证据写入 MUST 幂等——同一证据事件重复提交不产生重复记账
- **NFR-103**: 证据与掌握度变更 MUST 全量留痕（谁、何时、基于哪条证据、从什么状态到什么状态），支持按学习者回溯
- **NFR-104**: 任一自动判定 MUST 可撤销且在 5 秒内完成回退
- **NFR-105**: 推荐与诊断结果 MUST 可解释——每个结论附至少一条证据或依赖理由，不输出黑箱分数
- **NFR-106**: 题目与反馈内容 MUST 通过既有防偏离三重校验；校验服务不可用时 MUST fail-safe（不出题/不展示）
- **NFR-107**: 系统 MUST NOT 因学情服务的局部失败阻断阅读与会话（降级为"本次不更新学情"并提示）
- **NFR-108**: 学习者学习数据（作答、错误标签、对话证据）MUST 支持导出为可读格式
- **NFR-109**: 题目重复曝光 MUST 有配额控制（7 天内同题最多 1 次计入掌握度）
- **NFR-110**: 推送 MUST 可配置且默认低频（见 FR-130）
- **NFR-111**: 单章节诊断的题目生成 MUST 有超时与题量下限保底（不足 8 题时用题库补齐，仍不足则提示延迟诊断）
- **NFR-112**: 掌握度、推荐、错题标签的算法 MUST 版本化，算法升级后历史数据 MUST 可标注"旧算法生成"

## UX Brief

本章只描述本规格**新增**的界面与流程（路线、定位测、诊断、反馈、推荐、仪表盘、复习队列），既有阅读器、五模式会话与溯源卡片的形态沿用 `specs/001`，不在此重复。

设计假设：以手机竖屏、单用户单设备为主要形态；「我的」为仪表盘入口；周报周期为自然周；阅读器仍是产品默认落地页，其余模块皆为它服务而非与之并列。

### 1. 信息架构与导航

#### 1.1 模块关系

| 模块 | 定位 | 主要入口 | 返回规则 |
|---|---|---|---|
| **阅读器**（既有） | 产品主界面，全屏沉浸 | 默认落地页；学习中心/路线地图/推荐卡的任务跳转 | 返回回到来源页并保留滚动位置与锚点 |
| **学习中心** | 聚合页：今日推荐 + 欠账 + 今日复习 + 周报 | 底部导航第 3 格 | 是多数任务的"起点页"与"收工页" |
| **路线地图** | 阶段→模块→节点的全貌与进度 | 学习中心「查看全路线」、路线选择完成后的"看一眼全貌" | 返回学习中心；从节点进入阅读器后返回仍在地图原位 |
| **测试（定位测/章节诊断）** | 沉浸式全屏，中断即存档 | 阅读器章末、推荐卡、欠账条目 | 交卷后进报告页，报告页返回原触发点 |
| **诊断报告** | 章节级结论 + 可执行动作 | 测试交卷后自动进入；历史报告从「我的 → 学情」进入 | 动作跳转后可按"回到报告"返回，报告内容刷新而非重建 |
| **仪表盘** | 只读学情总览（雷达/热力/薄弱点 Top5/欠账） | 底部导航「我的」第二段 | 任一结论可下钻到节点与证据，证据链接跳到原文锚点 |
| **复习队列** | 今日到期的短任务流 | 学习中心「今日复习」卡 | 可随时退出，退出即保留进度，不阻断阅读 |

#### 1.2 移动端一级导航

- 底部四格：**阅读 · 路线 · 学习中心 · 我的**。默认选中「阅读」，进入即落在上次阅读位置（不是书库首页）。
- 「路线」格直达路线地图；若用户尚未选路线，该格显示为「选路线」并带一个未完成圆点。
- 「学习中心」角标只表示"有事要处理"（欠账或复习到期 >0），不做数字轰炸，超过 9 显示为 9+。
- 「我的」内含仪表盘、周报历史、提醒与推送设置、数据导出。
- **不破坏阅读器主形态**：
  1. 阅读时底部导航随滚动方向自动收起，向上滚动或点击屏幕底部边缘恢复。
  2. 选中文本弹出五模式工具栏时，底部导航下沉隐藏，工具栏为最高优先级（避免两排可点区域争抢拇指区）。
  3. 会话弹层展开时导航完全被覆盖（弹层为模态），关闭后回到原文与原文选中位置。
  4. 阅读器内只新增两个入口标记：顶部"所属路线 / 章节"面包屑（点击回路线地图），章末"本节已读完"结束条（触发诊断）。
- 测试、报告、仪表盘下钻、复习队列均为**整页推入**，不占用底部导航格。

### 2. 关键用户流程

#### 流程 A — 首次进入 → 选路线 → 定位测 → 起点建议 → 开始阅读

1. 首启欢迎页展示三张路线卡：目标描述、预计投入、首站推荐、内容完整度（"可完整学完"/"骨架已就绪，逐章开放中"）。
2. 每张卡可展开"阶段—模块全貌"，只读预览，不做选择；关掉预览不影响已选卡片。
3. 点选路线 → 底部确认条："主路线随时可换，已学记录全部保留"，两个动作【就这条】【再看看】。
4. 进入定位测说明页：题量（8–15）、预计时长、"也可以跳过，从第一章开始"的次要出口。
5. 逐题作答：单题作答即存，顶部进度"第 n / N 题"；中途退出保留断点。
6. 交卷后进入起点结果页：起点章节与节、3 条理由（前置未满足 / 能解锁的下游数量 / 已有证据）、"已掌握可跳过"清单、预计耗时。
7. 两个出口：【从这里开始】直接进入该节阅读器，顶部一次性提示"起点已设为…（可修改）"；【我要从更早处开始】让用户在地图上手动指定。

**关键分支**

- 定位测中途退出超过 24 小时：再次进入先问"继续上次 / 重新开始"，重做会保留上一次结果作为参考。
- 定位题量不足（见 FR-107 的降级）：结果页顶部加"本次定位参考度有限"徽标，并说明原因与补救（"读完第一章后做一次诊断即可校准"）。
- 人工指定起点：起点建议折叠为"系统建议（未采纳）"保留，不删除、不降权为零（见 FR-108）。
- 已有学情的老用户：跳过定位测，直接从学习中心给推荐；起点结果页不存在。

#### 流程 B — 学完一节 → 触发诊断 → 看报告 → 执行下一步

1. 阅读器滚动到节末出现结束条：主按钮【做掌握度诊断（约 12 题，8 分钟）】，次按钮【稍后】【先去会话】。
2. 进入测试页：顶部"章节名 · 第 n/N 题"与题型标签；副标题可展开"本次覆盖的知识点"清单。
3. 客观题作答即判：正确给一句"为什么对"，错误展开三段——错误类型标签 + 所选干扰项与正确项的差异 + 原文锚点链接。
4. 迁移题：显示"判定中"，低置信时转为"待确认"，给自评入口，明确告知"不计入掌握度"。
5. 交卷进入报告页，自上而下：掌握度分布 → 错误类型分布 → 薄弱点 Top3（每条带一个动作）→【下一步】主按钮 + 2 个次动作 → 底部【回到原文】【继续下一章】。
6. 点薄弱点动作 → 直达解析层指定段落，段落末尾紧跟 2 道专项题；完成后回到报告页，该条就地更新为"已处理"（不整页重建）。

**关键分支**

- 中断、掉线、来电：按题保存；重入提示"从第 n 题继续"，已判分的题不允许改答案。
- 全部答对：报告缩为"晋级卡"——一句话结论 + 【下一章】+ 可选"加做 2 道迁移题"。
- 同一知识点连续 3 次答错：报告中该节点标"已进补丁队列"，动作换成【立即打补丁】（见 FR-111、Edge Cases）。
- 判分服务不可用：客观题照常出结果；报告顶部一条灰条"主观题判定暂缓，结论待补"，不给出虚假完整结论。

#### 流程 C — 会话结束 → 小结卡 → 确认或纠正系统判定

1. 会话中任意时刻点【结束本节】；满 5 轮后底部出现"结束本节并生成小结"引导。
2. 小结卡以半屏卡片从底部升起（不是整页）：三段——**已理解 / 待纠正 / 建议下一问**，每段 ≤3 条。
3. 每条判定右侧一个"…"：【我不认同】→ 二选一"我还没掌握"或"我其实已经懂了" → 提交后该条灰显并标"已撤销·以你为准"。
4. 底部主按钮【收进本节笔记】，次按钮【继续追问】（回到同一弹层，锚点不变）。
5. 关闭后：阅读器右侧批注轨出现本次会话标记；被撤销的条目不再作为薄弱证据出现在仪表盘与推荐中。

**关键分支**

- 学情写入失败：卡片顶部提示"本次学情未保存"+【重试】，关闭按钮始终可用（见 NFR-107）。
- 离线：卡片显示"待同步"小徽标，恢复后自动补写，不弹二次确认。
- 与显式测试冲突：卡片对应条目直接标注"与 X 天前的测试不一致，以测试为准"（见 FR-115），并给"查看那次测试"的下钻。

#### 流程 D — 打开学习中心 → 看推荐与欠账 → 做补丁或复习

1. 学习中心三段式：顶部"今日推荐"（1 主 + ≤2 备选）、中部"欠账 N 项"、下部"今日复习 M 条"；右上角周报入口，有新周报时只加一个红点。
2. 推荐主卡可展开理由标签（依赖 / 杠杆 / 欠账 / 到期复习）与预计耗时，主按钮【开始】直接落到对应节点。
3. 点开欠账条目 → 欠账详情：哪个节点、由哪条证据判为未达标、补丁内容（定段 + 专项题数）、"约 10 分钟"标记；主按钮【开始补丁】。
4. 点复习卡 → 复习队列页；到期超过 20 条时，首屏就给"只做 5 项"的降级按钮（见 FR-133）。
5. 任一项完成后回到学习中心，卡片就地更新计数与勾选状态，不做整页刷新、不打断滚动位置。

**关键分支**

- 连续 3 次未采纳推荐：推荐区改为更小单元（单节 / 单概念），并给"你更想怎么学"的三选一偏好（见 FR-112）。
- 推荐命中未上线章节：卡片上直接标"该章尚未开放"并给同路线替代节点 + "上线后提醒我"（见 FR-111 与 Edge Cases）。
- 无任何学习历史：学习中心呈现引导态——三张路线卡 + 一句"选一条路线，先做一次定位测"。
- 离线：只显示已缓存推荐，卡片带"离线数据，仅供参考"标注；欠账与复习可只读浏览、不可开始。

### 3. 界面与组件状态

#### 3.1 路线地图

- **空**：尚未选择路线 → 三张路线卡的引导 + "选一条开始"；已选路线但该路线内容均未开放 → "这条路线正在入库，先看其他两条"。
- **加载**：先用骨架画出阶段骨架（阶段名 + 模块占位），不显示假进度。
- **正常**：竖屏为纵向路径，阶段为分组头，节点为可点圆点；节点用"未接触 / 进行中 / 已掌握 / 欠账 / 未开放"五种标记，每处都带文字标签与图标，不靠颜色单独区分。
- **部分失败**：进度计算失败时，地图照常可读可点，顶部一条"进度暂不可用"提示 + 【重试】，节点点击仍可进入阅读。
- **离线**：显示上次缓存的地图与进度，顶部"离线 · 进度可能不是最新"，节点可读，测试类入口置灰。
- **内容未上线**：节点为虚线描边 + "未开放"标签，点击弹一行说明与"上线提醒我"，不出现死链。

#### 3.2 定位测

- **空**：无可组成定位卷的题目 → 直接跳到降级路径（章节抽样阅读 + 5 题快测），并说明"定位精度较低"。
- **加载**：说明页先出（题量、时长、可跳过），组卷在说明页期间完成，不出现白屏。
- **正常**：单题一屏，进度、题型标签、"本题所属阶段"小注；作答即存，上一题可回看不可改。
- **部分失败**：某题判分失败 → 该题不计分并标注"本题作废"，最终结果页说明覆盖度受损；整体不出错。
- **离线**：允许离线作答已下发的题，交卷时提示"连网后生成起点建议"，结果页转为待生成态。
- **内容未上线**：抽取到未开放阶段时跳过该阶段，并在结果页注明"本次未覆盖第 X 阶段"。

#### 3.3 诊断报告

- **空**：无可判分内容（全部题作废）→ "本次诊断未形成结论"+【重新诊断】【先继续阅读】，不给出半成品结论。
- **加载**：报告分段流式出现（分布 → 错误类型 → 薄弱点 → 下一步），先到的部分可读，不必等全部。
- **正常**：三段结构 + 底部动作区；每个薄弱点一行标题 + 一行证据 + 一个动作按钮。
- **部分失败**：主观题待确认 → 顶部灰条"判定暂缓"，报告中该节点标"待确认"且不参与薄弱点排序；其余结论照常可用。
- **离线**：只展示本地缓存报告，动作按钮保留但点击提示"需连网"；"回到原文"仍可用。
- **内容未上线**：报告涉及的锚点段落未上线时，动作改为"该段落内容入库中"+ 替代动作（同章其他段落 / 3 道同类专项题）。

#### 3.4 小结卡

- **空**：本轮无可抽取证据（例如只问了一句就结束）→ "这轮对话没留下可评估的内容"+【继续追问】【关闭】，不硬凑判定。
- **加载**：卡片先出骨架，三段标题可见，内容逐条淡入，最多等 3 秒后转为"稍后自动收进笔记"。
- **正常**：三段各 ≤3 条，条条可撤销；底部主/次按钮。
- **部分失败**：某条抽取失败 → 该条显示"未能评估"占位，其余照常；不整卡失败。
- **离线**：卡片可正常生成（本地缓存的问题与判定），顶部"待同步"徽标；撤销操作排队。
- **内容未上线**：建议下一问若指向未上线段落，替换为同章可读问题，并注明"原文段落暂未开放"。

#### 3.5 推荐卡

- **空**：无前沿节点（路线已全部学完）→ "这条路线已走完"+【看仪表盘】【换一条路线】。
- **加载**：一张主卡骨架，备选位留空，不占位抖动；超过 2 秒显示"正在挑选最值得学的一节"。
- **正常**：主卡含章节、预计耗时、理由标签、一句话推荐语、【开始】；备选 ≤2 条折行显示。
- **部分失败**：推荐计算失败 → 退回"上次推荐"并标"未更新"，不展示空白；用户仍可手动从地图进入。
- **离线**：展示缓存推荐 + "离线数据"标注，【开始】仅在内容已缓存时可用。
- **内容未上线**：卡上标"该章尚未开放"，主按钮变为【看替代节点】，并给上线提醒入口。

#### 3.6 欠账列表

- **空**：无欠账 → 一句"暂时没有欠账"+ 最近一次诊断的结论摘要，不做庆祝式动效。
- **加载**：三行骨架；不显示数字直到算出。
- **正常**：按"杠杆值 × 欠账程度"排序，每行 = 节点名 + 一句原因 + 补丁按钮 + "约 X 分钟"。
- **部分失败**：部分条目计算失败 → 该条目显示"补丁生成中"，其余可执行；顶部提示"部分补丁未就绪"。
- **离线**：只读列表，按钮置灰并提示"连网后可开始"。
- **内容未上线**：该条目保留（欠账不因未上线而消失），按钮换为"等待该章开放"+ 提醒入口。

#### 3.7 仪表盘雷达

- **空**：无证据 → 灰底雷达 + 一行"完成一次诊断后这里会亮起来"+ 直达入口；不以 0 分形似"能力为零"。
- **加载**：轴与刻度先绘制，多边形淡入；不出现伪数据。
- **正常**：五维雷达 + 每维等级词 + 与上次对比的箭头（上升/下降/持平，箭头带文字说明）；点击任一维进入下钻。
- **部分失败**：某维数据缺失 → 该轴标"数据不足"并留断口，不按 0 处理；整体照常可读。
- **离线**：显示缓存快照 + "截至 X 月 X 日"时间戳；下钻到证据时提示需连网。
- **内容未上线**：涉及未上线章节的维度标"部分证据待补"，不改变已算出的分值。

#### 3.8 复习队列

- **空**：今日无到期 → "今天没有到期复习"+ 下一个到期日；给"提前复习 5 项"的可选入口。
- **加载**：单张卡片骨架 + 进度"第 1 项"。
- **正常**：一次一项，卡面 = 概念卡 / 旧错题 / 苏格拉底问题三种之一；完成后给"容易 / 一般 / 困难"三档评级，立即进入下一项。
- **部分失败**：某卡内容缺失 → 跳过并标"本次跳过"，队列总数相应减少，结束时说明跳过了几项。
- **离线**：可用已缓存的卡片；评级本地暂存，恢复后补写；未缓存卡片显示"需连网"。
- **内容未上线**：队列不含未上线节点的卡片；若到期项全为未上线内容，显示"到期项所在章节尚未开放"+ 提醒入口。

### 4. 反馈文案策略

#### 4.1 让"下一步"可执行

- 每条反馈（小结卡/报告/周报）**必须**落在动词开头的动作上：跳段、做题、复习、换起点、结束本节；不得以"你比较薄弱"收尾（见 FR-127）。
- 动作文案结构统一为「动词 + 具体对象 + 位置 + 预计耗时」，例如：
  - 好："回第 1 条解析层『实践≠道德践履』，读到第 3 段（约 4 分钟）"
  - 好："做 2 道『术语混用』专项题（约 3 分钟）"
  - 差："巩固一下实践概念"
- 主按钮 ≤10 字且只有一个；次动作最多 2 个，用文字链，不与主按钮抢视觉权重。
- 任何结论后面必须能点出一个"凭什么"：一行证据（哪道题/哪轮对话/哪段原文）。

#### 4.2 三档反馈的长度上限

| 档位 | 载体 | 长度上限 | 结构要求 |
|---|---|---|---|
| 回合级 | 小结卡（半屏） | 三段 ×≤3 条，单条 ≤28 字；全卡 ≤200 字 | 已理解 / 待纠正 / 建议下一问，段名固定 |
| 章节级 | 诊断报告 | ≤3 屏，滚动一次可读完；每个薄弱点说明 ≤60 字，动作 ≤20 字 | 分布 → 错误类型 → 薄弱点 Top3 → 动作 |
| 周期级 | 周报 | ≤1 屏；正文 ≤120 字 + 5 个数字指标 | 增量 → 雷达变化 → 欠账 → 复习到期 → 路线偏离 |

- 超限即视为文案缺陷：编辑必须删到上限内，不允许"展开查看更多"来绕过。
- 数字指标最多 5 个；增量为 0 的指标不显示，避免制造噪声。

#### 4.3 薄弱点的表述规范

- 规则：**描述证据与情境，不做能力或人格评判**；不使用"差 / 弱 / 不行 / 根本没懂"类形容词修饰学习者；不与他人比较。
- 弱点的三段式：① 在什么情境 ② 出现了什么具体混淆 ③ 建议回到哪一段。
- 正例：
  1. "在『否定之否定』的 2 道逻辑推演题里，你把『扬弃』读成了『取消』（3 天前 · 诊断）"
  2. "上次会话中你把『实践』用成了日常行为；诊断结果与之一致，建议回到第 1 条解析层"
- 反例：
  1. "你基础太差，建议从头学起"（评判能力 + 无可执行动作）
  2. "你的辩证法理解很薄弱"（形容词结论，无证据、无位置）
- 错误类型标签一律"标签 + 一句人话解释"成对出现，例如"术语混用：把两个不同层次的概念当同义词用了"；标签只用于解释错题，不展示为对人的评价（见 R-106）。
- 掌握度不显示两位小数百分比，只显示等级词 + "暂定 / 已确认"；置信度不以数字呈现。
- 禁止承诺类措辞："保证掌握""彻底搞懂""押中考点"一律不用。
- 失败与空状态文案以"现在能做什么"结尾，不以"出错了"结尾。

### 5. 可访问性与适配

#### 5.1 键盘等价路径

- 全局：Tab 顺序与视觉顺序一致；Esc 关闭当前层并回到发起处；不出现只能用点按触发的动作。
- 学习中心：推荐主卡 → 备选条目 → 欠账列表 → 复习卡 → 周报入口；Enter 进入，展开理由用 Enter 或空格。
- 路线地图：方向键在节点间移动（同阶段上下、跨阶段左右），Enter 进入节点，Esc 回到学习中心；提供"列表视图"作为地图的完全等价替代。
- 测试页：数字键 1–4 选择选项，Enter 确认并进入下一题，Esc 退出并弹"保存并离开"行内确认；主观题 TextArea 内 Enter 换行、Ctrl/Cmd+Enter 提交。
- 报告页与小结卡：动作按钮可 Tab 直达；撤销判定用 Enter 展开、Esc 收起。
- 复习队列：空格翻面、1/2/3 对应"容易 / 一般 / 困难"、Esc 退出。

#### 5.2 屏幕阅读器替代文本

- **雷达图**：必须提供"表格视图"切换，逐维读出"唯物论 熟悉，较上次上升一档；辩证法 初学…"；图形本身不作为唯一信息来源。
- **热力图**：提供文本摘要——"最近 7 天学习 5 天，最长连续 3 天；最近 30 天共 18 次会话、6 次诊断"；单格可聚焦读出日期与活动条数。
- **路线地图**：列表视图按阶段展开节点名、状态、前置依赖与"可开始 / 未开放"，与地图信息一一对应。
- **错误类型分布条**：逐段读出"术语混用 4 题，共 12 题"，不读成"红色 4"。
- 状态变化（掌握度升级、判定被撤销、推荐换新）用礼貌播报，不打断当前阅读或作答。

#### 5.3 色彩不作为唯一信息载体

- 六类错误类型标签各有固定"色 + 图标 + 文字短标签"（如"概念层次混淆"配分层图标），沿用既有非纯色原则。
- 节点五态（未接触 / 进行中 / 已掌握 / 欠账 / 未开放）在色块外必须有图标与文字；虚线代表"未开放"，实线代表"可学"。
- 雷达的五边形在灰度打印或高对比主题下仍能区分：每条轴有独立标签与端点数值文字。
- 上升 / 下降不只靠绿红：配箭头方向 + "+1 档 / −1 档"文字。

#### 5.4 小屏、横屏与字号

- 小屏（≈360dp 宽）：推荐备选折进"更多方案"；报告强制单列；雷达图先出表格视图，图形作为可选展开。
- 横屏：报告页雷达与薄弱点双栏；测试页题干在左、选项在右；路线地图转为横向时间轴，与竖屏纵向路径信息等价。
- 字号缩放 1.0–2.0：全程可用；放大到 ≥1.3 时雷达与热力图自动切到文本视图；测试选项超过 3 行折叠为"展开全文"；按钮文字只换行不截断。
- 触控目标 ≥44dp；选中工具栏与底部导航不同时出现；戴手套/单手模式下主按钮固定在屏幕下半区可及范围。
- 遵循系统"减少动效"：小结卡与报告入场动画可关；作答题间不自动滚动到屏幕外位置。
- 朗读：小结卡与报告每条结论可逐条朗读（复用既有朗读能力），朗读时视觉焦点跟随对应条目。

### 6. 与既有界面的复用边界

#### 6.1 直接复用（不新做）

| 既有界面 | 复用方式 |
|---|---|
| 三层阅读器与批注轨 | 诊断/报告/推荐"跳转段落"一律落在此处，并高亮锚点 |
| 五模式工具栏 | 测试报告里的"去问一问"直接唤起对应模式，不再造入口 |
| 会话弹层及其头部 | 沿用模式切换与批判性阅读开关；小结卡以此为宿主 |
| 溯源卡 | 报告与错题解释中的"原文锚点"沿用同一张卡，不新做证据卡 |
| 拦截卡 / 兜底卡 | 报告与推荐的所有"算不出/不展示"状态沿用同一视觉 |
| 章末小结弹层外壳 | 改造为本章"章节小结"的数据来源，外壳与交互不变 |
| 雷达图渲染器 | 仪表盘与诊断报告共用同一图形 + 表格视图能力 |
| 概念锚点卡 | 路线地图与欠账详情里点概念时复用 |

#### 6.2 新增（必须在整页层实现，不进弹层）

- 起点结果页（定位测结束后一次性使用）。
- 测试页：题型标签、作答即判、待确认态、断点续做。
- 诊断报告页：分布 → 错误类型 → 薄弱点 → 动作的四段式。
- 仪表盘下钻页：维度 → 节点 → 证据的逐层列表。
- 复习队列页：单卡式，含三档评级与降级模式。
- 学习中心推荐区：复用推荐卡渲染器，新增"理由标签 + 预计耗时"行与"未开放"标记。

#### 6.3 避免弹层套弹层（硬规则）

1. **同屏最多一层模态**。会话弹层已开时，小结卡不叠第二层：弹层先收起到 ≤40% 高度，小结卡作为同层"续页"在原位展开，关闭小结卡即回到会话。
2. **整页动作先收弹层再推页**：从会话弹层发起测试或跳报告，一律先关闭弹层、再整页推入；返回时恢复到原选中锚点，不重开弹层。
3. **确认不进对话框**：撤销判定、放弃测试、退出定位测等确认，用行内展开或底部单行确认条，禁止"弹层里再弹确认框"。
4. 唯一例外：系统级权限与推送开关沿用平台标准对话框，不自行设计。
5. 任一深层页面都必须有"回到上一层"的显式出口，且回到的层级与进入时一致（报告 → 测试来源 → 原文）。
