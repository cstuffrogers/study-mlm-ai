# Feature Specification: 三路线学习与学情闭环（学习路线 · 章节掌握度 · AI 反馈推荐）

**Feature Branch**: `002-learning-routes-mastery`

**Created**: 2026-11-04

**Status**: Draft

**Input**: User description: "根据 路径.txt 中提到的学习路径，分成3个学习路线——纯理论研究、组织革命、建设社会主义国家；结合本项目功能，设计怎么帮学生更好学习掌握：按顺序一章章学，AI 测试掌握情况，也在对话中学习并更新学情，AI 及时总结反馈找出薄弱点、推荐从哪个章节开展学习，还要有测试环节。产出完整的方案。"

> 本规格聚焦「学习路径 / 学情闭环 / 测试 / 反馈推荐」这一全新能力层。它建立在既有 MVP（《关于费尔巴哈的提纲》精读闭环 + 防偏离三重机制 + RAG + 溯源卡片）之上，**复用**而非重建精读与防偏离能力，**新增**路线组织、测试引擎、学情引擎、路径推荐引擎。

## Clarifications

### Session 2026-11-04

- Q: 三条路线与学习顺序的关系是「三选一」还是共享地基？ → A: 采用「1+3」结构——三条路线共享公共地基（马恩哲学基础：建坐标系+马克思本人核心+实践论/矛盾论），再分别进入纯理论深造 / 组织革命 / 建设社会主义国家支线（推荐方案）。
- Q: 默认学习节奏是「严格线性」还是「自适应」？ → A: 「主线固定、节奏自适应」——先做诊断性摸底测定位起点，之后沿主线顺序推进，但每章入口有可跳过的前测、每章出口有掌握度门控（推荐方案）。
- Q: 学情更新的信号来源？ → A: 测试（显式，高权重）+ 对话行为（隐式，低权重平滑）+ 费曼输出混合驱动（推荐方案）。
- Q: 三道学习路线的测试是否各自独立出题与判分？ → A: 是，三条路线各自维护独立题库与判分逻辑，但共享同一套知识点节点与掌握度模型（推荐方案）。
- Q: 本功能交付范围（分章分批 vs 三条路线完整题库一次到位）？ → A: 先做 P0「单章（提纲）学情闭环」可跑原型，再按路线分批扩展题库与章节（推荐方案）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 选择学习路线并从正确起点开始 (Priority: P1)

学习者首次进入系统，被要求从三条学习路线中选择一条：**A 纯理论研究**、**B 组织革命**、**C 建设社会主义国家**。系统说明三条路线共享公共地基，并展示每条路线的章节构成与预计时长。选定后，系统通过一次简短的「诊断性摸底测」评估其现有水平，给出**推荐起步章节与学习顺序**，而不是让每个人从第一页开始。

**Why this priority**: 路线与起点是后续所有学习动作的前提——没有路线就没有章节顺序，没有起点就无法"个性化"。它把 路径.txt 的静态书单转化为可执行、可导航的学习旅程，是差异化价值的入口。

**Independent Test**: 新用户选择路线 B，完成 10 题摸底测，系统输出"建议从《怎么办？》第 1 章起步，可跳过《共产党宣言》基础节"的推荐，并可一键进入该章。

**Acceptance Scenarios**:

1. **Given** 新用户首次进入，**When** 浏览三条路线介绍，**Then** 可见每条路线的目标说明、章节列表、预计时长，且明确标注"三条路线共享公共地基"。
2. **Given** 用户选择路线 A，**When** 完成诊断性摸底测，**Then** 系统输出推荐起步章节、推荐顺序、以及"可跳过/需补强"的章节清单。
3. **Given** 用户对推荐起点有异议，**When** 手动选择其他章节，**Then** 系统允许覆盖推荐，但提示"该章存在未掌握的前置知识点"并列出前置薄弱点。
4. **Given** 用户中途切换路线，**When** 确认切换，**Then** 已产生的学情数据保留，系统据此重算新路线的起点与顺序。

### User Story 2 - 逐章学习闭环（精读 + 对话 + AI 即时小结）(Priority: P1)

学习者在某章内阅读原著，选中文本唤起 AI 会话（复用既有五模式与防偏离机制）进行释义/追问/关联学习。每完成一段或一个知识点的交互，AI 会**即时小结**本节要点、点出用户在对话中暴露的薄弱点，并抛出 1 个检验性问题。整章结束时 AI 生成一份章节小结与"待巩固清单"。

**Why this priority**: 这是"在书本上学习并同步更新学情"的核心体验，直接复用现有精读与防偏离能力，是学情数据的**隐式来源**。没有它，学情只能靠考试，体验割裂。

**Independent Test**: 用户在《提纲》第 6 条选中"市民社会"，用【追问】模式对话 3 轮，系统在每轮后给出要点小结，并在章节结束时输出包含"市民社会概念层次混淆"的待巩固清单。

**Acceptance Scenarios**:

1. **Given** 用户在章内与 AI 对话，**When** 一轮问答结束，**Then** AI 给出本节要点小结 + 1 个检验性问题（不打断阅读节奏）。
2. **Given** 用户在同一概念上反复追问或答错，**When** 系统检测到该信号，**Then** 将其记录为"对话暴露薄弱点"，进入该知识点的隐式学情。
3. **Given** 用户完成一章阅读，**When** 触发章节小结，**Then** AI 输出"本章要点 + 薄弱点清单 + 建议先做的测试题"，并汇总进学情档案。
4. **Given** 对话中出现偏离正统表述，**When** 触发既有防偏离拦截，**Then** 学情引擎不得把"被判为偏离的内容"当作普通错题，而应标注为"需西马批判对象模式引导"。

### User Story 3 - 章节测试与掌握度诊断 (Priority: P1)

学习者完成一章后进入**章节测试**，题型覆盖四类：概念辨析、文本定位、逻辑推演、错误诊断。系统判分后，将每个知识点标记为五级掌握度（未接触/初学/熟悉/精通/贯通），并给出错因归类（真不懂 / 术语误用 / 概念层次混淆 / 立场偏移）。测试采用**正确率 + 难度 + 复核**综合判定，达到门槛才判定为掌握。

**Why this priority**: 测试是学情最可靠的**显式来源**，也是"这个知识点你真的懂了吗"的量化依据，是产品区别于"已读型 App"的关键。没有可验证的测试，掌握度无法成立。

**Independent Test**: 用户完成《提纲》章节测试，答错"市民社会"概念辨析题，系统将"市民社会"标记为"初学"，错因标注为"概念层次混淆"，并给出对应复习建议。

**Acceptance Scenarios**:

1. **Given** 用户完成一章，**When** 触发章节测试，**Then** 系统生成覆盖本章核心知识点的四类题型，题量按知识点规模自适应（默认 8–12 题）。
2. **Given** 用户作答完毕，**When** 系统判分，**Then** 输出每个知识点的五级掌握状态与错因归类，并附错题的正统解析与原文溯源。
3. **Given** 用户某知识点连续多次测试错误，**When** 系统诊断，**Then** 标记为薄弱点并触发专项补强（插入前置章节段落或同级专项题）。
4. **Given** 主观题（论述/费曼）提交，**When** AI 批改，**Then** 从"术语正统性 / 逻辑自洽 / 概念层次"三维度给修改建议而非直接重写。

### User Story 4 - 学情档案与薄弱点反馈 (Priority: P2)

学习者拥有一个**学情档案**，汇总所有章节的知识点掌握度、对话暴露的问题、测试错因、费曼批改结论。系统按"掌握度低 × 依赖出度高 × 考频/重要性"综合排序，持续输出**薄弱点 TOP-N** 与能力雷达（唯物论 / 辩证法 / 认识论 / 历史唯物主义 / 政治经济学），并定期生成**AI 学习总结反馈**（本周学了什么、卡在哪里、下一步建议）。

**Why this priority**: 学情档案是"及时总结反馈"的载体，把零散的测试与对话沉淀为可行动洞见。它依赖 US1–US3 的数据积累，故排 P2，但它是"找薄弱点"这一核心诉求的直接交付。

**Independent Test**: 用户学习两周后打开学情档案，可见能力雷达、薄弱点 TOP5、以及一份自动生成的"本周学习总结"。

**Acceptance Scenarios**:

1. **Given** 用户已有多章学习数据，**When** 打开学情档案，**Then** 可见知识点掌握分布、五维能力雷达、薄弱点 TOP-N（含排序依据）。
2. **Given** 用户连续多日学习，**When** 触发生成学习总结，**Then** AI 输出"已掌握 / 待巩固 / 下一步建议"，并标注数据来源（测试/对话/费曼）。
3. **Given** 某薄弱点是多个后续章节的前置依赖，**When** 计算薄弱点排序，**Then** 该知识点优先级上调并标注"阻塞后续 N 个章节"。

### User Story 5 - 智能路径推荐与解锁门控 (Priority: P2)

基于学情档案，系统**主动推荐下一步该学/该复习哪个章节**：达到门槛的章节解锁下一章；未达门槛的章节回退或插入补强；跨章薄弱点在多个后续章节中被依赖时，推荐先回补该薄弱章节。推荐给出一句话理由（"你在'对立统一规律'连续出错，建议先回补《矛盾论》专项"）。

**Why this priority**: 推荐与门控把学情转化为**行动**，是"推荐从哪个章节开展学习"诉求的落点。它依赖 US4 的学情排序，故排 P2。

**Independent Test**: 用户在"对立统一规律"连续 3 次测试错误，系统推荐"先完成《矛盾论》第 3 节专项训练"并暂时锁定《德意志意识形态》下一章入口。

**Acceptance Scenarios**:

1. **Given** 某章掌握度达到解锁门槛（默认 80%），**When** 用户查看路径，**Then** 下一章标记为"已解锁"。
2. **Given** 某章掌握度未达门槛，**When** 用户尝试进入下一章，**Then** 系统拒绝并给出"需先补强 X 知识点"的推荐与快捷入口。
3. **Given** 用户存在阻塞性薄弱点，**When** 打开首页，**Then** 首屏展示"今日推荐：从 X 章 Y 节开始"及一句话理由。

### Edge Cases

- **路线切换**：用户已学 A 路线若干章后切到 B，公共地基章节的掌握度可复用，支线章节需重新评估，不得清零已有学情。
- **跳过测试**：用户拒绝做摸底测直接选起点时，系统允许，但标注"掌握度暂不可信，仅作初值"，并在首次章节测试后校正。
- **防偏离与学情冲突**：对话中被判为"偏离"的内容，禁止直接计为普通错题，须走批判对象/双轨制通道，避免把"能正确批判西马"误判为"立场错误"。
- **题目争议**：用户对判分有异议时可申诉，申诉进入专家审核队列（复用既有审核能力），人工裁定后回写题库与学情。
- **跨设备/断点续学**：学习进度、学情档案、当前章节位置需在多端同步、不丢失。
- **知识图谱缺口**：某章节尚无知识点节点树时，降级为"按段落学习 + 简化测试"，并提示"该章精细化诊断待内容补全"。
- **无足够题目**：题库不足时，禁止用 AI 凭空生成无溯源答案直接判分，须标注"题目权威性待审核"或拒绝出题。

## Requirements *(mandatory)*

### Functional Requirements

**路线与导航**

- **FR-001**: 系统 MUST 提供三条学习路线：A 纯理论研究、B 组织革命、C 建设社会主义国家，每条含目标说明、章节列表、预计时长。
- **FR-002**: 系统 MUST 采用「1+3」结构——三条路线共享公共地基（马克思主义哲学基础章节），再各自进入专属支线；公共地基的掌握度在路线间复用。
- **FR-003**: 系统 MUST 支持用户切换路线，切换时保留已有学情数据并据此重算新路线的起点与顺序。
- **FR-004**: 系统 MUST 为每条路线维护独立的章节顺序与题库，但共享同一套知识点节点与掌握度模型。

**起点与顺序**

- **FR-005**: 系统 MUST 通过诊断性摸底测评估用户初始水平，产出推荐起步章节、推荐学习顺序、可跳过/需补强清单。
- **FR-006**: 系统 MUST 采用「主线固定、节奏自适应」：默认沿路线主线顺序推进，允许章前前测跳过已掌握章节，允许手动覆盖推荐起点（附前置薄弱提示）。

**逐章学习闭环**

- **FR-007**: 系统 MUST 在章内复用既有精读与五模式 AI 会话能力，并在每轮问答后输出要点小结与检验性问题。
- **FR-008**: 系统 MUST 在章节结束时生成章节小结与"待巩固清单"，并汇总进学情档案。
- **FR-009**: 系统 MUST 从对话行为中提取隐式学情信号（反复追问、被追问即卡顿、答错被驳回、关联失败），并降权平滑地并入知识点掌握度。

**测试与掌握度**

- **FR-010**: 系统 MUST 提供四类测试题型：概念辨析、文本定位、逻辑推演、错误诊断。
- **FR-011**: 系统 MUST 对每章按知识点规模自适应出题（默认 8–12 题），并支持摸底测与章节测试两种场景。
- **FR-012**: 系统 MUST 将每个知识点标记为五级掌握度（未接触/初学/熟悉/精通/贯通），判定综合正确率、难度、复核三因素。
- **FR-013**: 系统 MUST 对错题输出错因归类（真不懂 / 术语误用 / 概念层次混淆 / 立场偏移）及正统解析与原文溯源。
- **FR-014**: 系统 MUST 对主观题（论述/费曼）做三维度批改（术语正统性/逻辑自洽/概念层次），给出修改建议而非代写。

**学情档案与反馈**

- **FR-015**: 系统 MUST 维护统一学情档案，汇总知识点掌握度、对话暴露问题、测试错因、费曼批改结论。
- **FR-016**: 系统 MUST 按"掌握度低 × 依赖出度高 × 考频/重要性"输出薄弱点 TOP-N，并标注阻塞后续章节数。
- **FR-017**: 系统 MUST 提供五维能力雷达（唯物论 / 辩证法 / 认识论 / 历史唯物主义 / 政治经济学）。
- **FR-018**: 系统 MUST 定期生成 AI 学习总结反馈（已掌握/待巩固/下一步建议），并标注每条结论的数据来源。

**路径推荐与门控**

- **FR-019**: 系统 MUST 在掌握度达门槛（默认 80%）时解锁下一章，未达门槛时拒绝解锁并给出补强推荐与快捷入口。
- **FR-020**: 系统 MUST 在首页/关键节点给出"今日推荐：从 X 章 Y 节开始"及一句话理由。
- **FR-021**: 系统 MUST 支持用户对判分申诉，申诉进入专家审核队列，人工裁定后回写题库与学情。

**正统性与安全（延续既有红线）**

- **FR-022**: 测试题库与标准答案 MUST 溯源锚定到原著分块（TextChunk），AI 仅辅助出题，产出须经既有三重校验（事实/术语/立场）方可入题库；不得凭空生成无溯源答案直接判分。
- **FR-023**: 错误诊断题中的"故意错误项"（机械唯物/唯心/修正主义话术）MUST 走豁免标记，避免防偏离机制误拦正确设计的错误选项。
- **FR-024**: 学情引擎 MUST 区分"真不懂"与"立场偏移"，后者引导至批判对象/双轨制模式，不计为普通错题。

### Key Entities *(include if data involved)*

- **LearningRoute（学习路线）**: 路线标识（A/B/C）、名称、目标说明、预计时长、章节序列、是否共享地基。
- **RouteSection（路线章节）**: 章节与路线的映射，含顺序、阶段号、所属著作、解锁门槛、前置依赖。
- **KnowledgeNode（知识点节点）**: 原子知识点，含所属章节、依赖关系、五级掌握状态、能力维度归属、考频/重要性权重。
- **MasteryRecord（掌握度记录）**: 用户 × 知识点 × 路线的掌握状态、判定依据（正确率/难度/复核）、最近更新时间、数据来源。
- **QuizItem（测验题）**: 题型（四类之一）、题干、选项/标准答案、难度、溯源 chunk_id、权威性状态（待审/已审）、豁免标记。
- **QuizAttempt（作答记录）**: 用户 × 题目作答、得分、耗时、错因归类。
- **SectionTest（章节测试）**: 某用户某章节的一次测试会话，含题组、总分、产出掌握度快照。
- **DiagnosticTest（摸底测）**: 用于起点评估的跨章节测试会话。
- **LearningProgress（学习进度）**: 用户 × 路线 × 章节的进度、当前锚点位置、解锁状态。
- **StruggleSignal（学情信号）**: 从对话/测试/费曼提取的薄弱点信号，含类型、强度、来源、关联知识点。
- **LearningProfile（学情档案）**: 用户维度的聚合视图与薄弱点排序、能力雷达、AI 总结记录。
- **Recommendation（推荐）**: 推荐类型（起步/下一章/回补/复习）、目标章节、理由、生成时间。
- **FeedbackReport（学习总结反馈）**: 定期生成的总结，含已掌握/待巩固/下一步及数据来源标注。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 首次使用者在 5 分钟内完成路线选择 + 摸底测，并拿到可执行的推荐起步章节。
- **SC-002**: 完成单章学习闭环的学习者，该章核心知识点测试平均正确率达到 70% 以上。
- **SC-003**: 系统给出的薄弱点 TOP-3 与专家人工诊断的一致率达到 80% 以上。
- **SC-004**: 路径推荐（下一章/回补/复习）被学习者在 72 小时内采纳并实际进入对应章节的比例达到 60% 以上。
- **SC-005**: 章节测试中"掌握度达标"判定与人工复核结论的一致率达到 85% 以上。
- **SC-006**: 学习者在连续 4 周使用后，对"系统能准确指出我的薄弱点"的主观评分达到 4 分（5 分制）以上。
- **SC-007**: 题库中有溯源锚定且经三重校验的题目占比达到 95% 以上（正统性保障）。
- **SC-008**: 90% 的学习者能在无人工协助下完成"选路线→摸底→学一章→测一章→看反馈→按推荐进入下一章"的完整一轮。

## Assumptions

- 沿用既有 MVP 已跑通的精读、五模式会话、防偏离三重机制、RAG 与溯源卡片，不作为本规格重建范围。
- 三条路线的章节内容来源于 路径.txt 与 学习顺序2.md 的书单；本规格只定义组织方式与学习机制，具体书目映射在 plan 阶段细化。
- **交付范围（本规格）**：先交付 P0「单章（提纲）学情闭环」可跑原型——含路线选择、摸底测、单章测试、掌握度、薄弱点反馈、下一章推荐；三条路线的完整题库与多章内容按路线分批扩展至后续迭代。
- 知识点节点、题库、标准答案需马哲专家参与编写/审核；AI 仅辅助出题与批改，不替代专家定稿。
- 目标用户为中国马克思主义哲学学习者（考研 / 考公 / 党校 / 党务 / 学术深造），具备基本中文阅读能力。
- 学习数据（学情、进度、作答）需持久化并跨设备同步。
- 五维能力维度定义为：唯物论 / 辩证法 / 认识论 / 历史唯物主义 / 政治经济学。
- 解锁门槛默认 80%，掌握度五级、题量 8–12 题等为可配置默认值，允许专家调整为路线级参数。

## Non-Functional Requirements (NFR)

- **NFR-001**: 章节测试判分 + 掌握度更新的端到端响应 MUST ≤ 3 秒（客观题）。
- **NFR-002**: 学情档案页与薄弱点排序查询 MUST ≤ 1 秒（首屏）。
- **NFR-003**: 路径推荐生成 MUST ≤ 2 秒，支持离线预计算缓存。
- **NFR-004**: 学情数据与学习进度 MUST 跨设备同步、断点续学不丢失，冲突以最近一次有效学习为准并留存历史。
- **NFR-005**: 所有测试题、标准答案、解析 MUST 可溯源到原著分块，且标注校验状态（待审/已审）。
- **NFR-006**: 学情隐私数据 MUST 按账号隔离，仅本人与授权专家/管理员可访问。

## Dependencies

- 依赖既有 MVP 的：精读器、五模式会话、防偏离三重机制、RAG 混合召回、溯源卡片。
- 依赖 路径.txt / 学习顺序2.md 提供的书目与阶段结构作为路线内容源。
- 依赖马哲专家提供知识点树、题库与标准答案定稿。

## UX 设计补充（UX Brief）

> 本节面向产品/运营/内容等非技术干系人，用通俗语言描述「三路线学习与学情闭环」的界面形态与交互体验。原则：**复用现有阅读器 + 五模式会话浮层，保持一致的操作心智**，新增能力以「轻量浮层 / 卡片」方式叠加，不打断阅读。

### 1. 关键界面与信息架构

以下页面构成完整学习闭环，建议以底部主导航串联：**路线导航（主）→ 章节学习 → 章节测试 → 学情档案**，路线选择与摸底测作为首次进入的前置引导流。

- **路线选择页（RoutePicker）**
  - 用途：首次进入时建立学习身份，选定 A 纯理论 / B 组织革命 / C 建设社会主义国家。
  - 核心元素：顶部「1+3」结构说明条（强调“三条路线共享公共地基”）；三张路线卡（路线名 + 一句话目标 + 章节目录预览 + 预计时长 + 难度/考频标签）；卡片可展开看完整章节清单；“选择此路线”主按钮；次级入口“先摸底再决定”“我已了解，直接选起点”。

- **摸底测页（DiagnosticTest）**
  - 用途：跨章节快速评估现有水平，为个性化起点提供依据。
  - 核心元素：顶部进度条 + “约 10 题 · 3 分钟”提示；单题卡片（四类题型外观统一，选项用大按钮）；右上弱化的“跳过摸底”入口（提示“跳过则掌握度暂不可信”）；交卷后的结果页（推荐起步章节 + 推荐顺序 + 可跳过/需补强清单 + “一键进入推荐章节”）。

- **路线导航 / 章节列表页（RouteMap）**
  - 用途：学习主地图，展示章节顺序与解锁状态。
  - 核心元素：顶部路线切换器（标注“共享地基”）；按阶段分组的章节节点列表（每节点含章名、所属著作、掌握度色点、状态徽章 🔒锁定 / ▶可学 / ✓已完成）；节点间连接线表达前置依赖；“今日推荐”置顶横幅（一句话理由 + 一键进入）；点击锁定章节弹出补强提示。

- **章节学习页（ChapterReader）**
  - 用途：章内精读 + AI 对话，边学边沉淀隐式学情。**复用现有三层阅读器与五模式浮层**。
  - 核心元素：沿用 AppBar 三层切换（原文/注释/解析）；术语高亮（沿用术语色）；选中文本 → 底部浮动五模式工具栏（沿用五色）；会话浮层为可拖拽底部弹层（沿用彩色竖线、溯源按钮、blocked 红卡）；**新增「即时小结卡」**（每轮问答后出现，要点 + 1 个检验性问题，默认折叠不打断）；章节结束弹出「章节小结 + 待巩固清单」卡，附“去测试”按钮。

- **章节测试页（SectionTest）**
  - 用途：显式诊断掌握度，是掌握度最可靠的量化来源。
  - 核心元素：题型混合进度 + 剩余题数；主观题输入区（论述 / 费曼）；交卷后的判分结果页（知识点 × 五级掌握度、错因标签、错题正统解析 + 溯源卡、申诉入口）；底部按门控状态显示“重测”或“进入下一章”。

- **学情档案 / 仪表盘页（ProfileDashboard）**
  - 用途：把零散测试与对话沉淀为可行动洞见，持续找薄弱点。
  - 核心元素：五维能力雷达（唯物论/辩证法/认识论/历史唯物主义/政治经济学）；章节 × 知识点掌握度热力图；**薄弱点 TOP-N 卡片**（含排序依据 + “阻塞后续 N 章”标签 + 快捷回补）；AI 学习总结反馈卡（已掌握 / 待巩固 / 下一步 + 每条的数据来源标注）；时间筛选（本周 / 全部）。

- **推荐卡片（RecommendationCard，跨页复用组件）**
  - 用途：把学情转化为下一步行动，出现在首页、导航页与档案页。
  - 核心元素：目标定位“从《X》第 Y 节开始” + **一句话理由** + 主按钮“一键进入” + 次按钮“先补强前置”。

### 2. 核心用户旅程（分步）

1. **新用户首次进入**：引导页说明三条路线与“共享地基”，进入路线选择。
2. **选路线**：在 A/B/C 中选择一条，可展开预览章节目录与预计时长。
3. **摸底测**：完成约 10 题诊断测；也可选择“跳过摸底”。
4. **拿到推荐起点**：系统给出推荐起步章节、推荐顺序、可跳过/需补强清单。
5. **学一章**：进入推荐章节，用三层阅读器精读，选中文本唤起五模式对话；每轮问答后出现折叠式即时小结。
6. **章节收尾**：阅读完成弹出「章节小结 + 待巩固清单」，点“去测试”。
7. **章节测试**：作答四类题型（含主观题），交卷后即时判分。
8. **看反馈**：看到知识点五级掌握度、错因归类、错题解析与溯源；档案与雷达同步更新。
9. **门控判定**：达标（默认 80%）则下一章“已解锁”；未达标则提示“需先补强 X 知识点”并给快捷入口。
10. **按推荐进入下一章**：首页/导航页的推荐卡“一键进入”，循环回第 5 步。

### 3. 关键交互细节

- **章前前测可跳过**：每章入口的前测右上角提供“跳过本章前测”，跳过不阻断学习，仅提示掌握度将随后续测试校正。
- **即时小结不打断阅读**：每轮对话后的小结默认收为一行摘要（如“本节要点 · 1 个检验问题”），用户点击才展开；不覆盖正文、不强制弹窗。
- **错题解析 + 溯源卡展开**：点任一错题 → 展开面板，依次呈现“错因归类 → 正统解析 → 溯源卡片”（复用现有溯源弹层形态），可逐层下钻。
- **薄弱点 TOP-N 卡**：按“掌握度低 × 依赖出度高 × 考频”排序；多个后续章节依赖的知识点带**“阻塞后续 N 章”标签**，并提供“回补”快捷按钮。
- **推荐卡一句话理由 + 一键进入**：如“你在‘对立统一规律’连续出错，建议先回补《矛盾论》专项”，主按钮直接跳到目标章节/专项。
- **判分申诉入口**：判分结果页每题与整卷角落设“对判分有异议？”入口 → 简短申诉表单（可附理由/截图）→ 进入专家审核队列 → 状态（待审/已裁定）回显给用户。

### 4. 空态 / 加载态 / 异常态

- **无学情空态**：新用户档案页显示友好插画 + 引导语“完成一次摸底测，生成你的专属路线”，主按钮“开始摸底”，弱入口“先随便逛逛”。
- **测试题目不足**：明确提示“该章题目权威性审核中”，提供降级方案“按段落学习 + 简化测试”，**禁止用 AI 凭空生成无溯源答案直接判分**，并标注“精细化诊断待内容补全”。
- **防偏离拦截时的批判对象引导**：沿用现有 blocked 红卡，但**新增引导按钮**“进入批判对象 / 双轨制模式”，并把该内容标注为“需引导”而非普通错题，避免把“能正确批判西马”误判为立场错误。
- **跨设备续学提示**：启动时若检测到其他端进度，弹出“检测到你在另一台设备学到《X》第 Y 节，是否继续？”→ “继续 / 查看学情档案”；以最近一次有效学习为准并保留历史。
- **加载态**：判分时显示“AI 判分中…”；档案页雷达/热力图用骨架屏占位，避免空白跳动。
- **网络异常**：已缓存正文可离线阅读；作答本地暂存，恢复网络后自动同步并提示“已同步 N 条作答”。

### 5. 视觉与体验原则

- **五模式配色与现有一致**：释义=蓝 `#3B82F6`、追问=绿 `#10B981`、辩难=红 `#E11D48`、关联=橙 `#F59E0B`、应试=紫 `#8B5CF6`；凡与某模式相关的元素（按钮、会话竖线、标签）一律沿用其对应色，保持心智连续。
- **掌握度五级统一色阶**（复用既有色板，全局一致）：未接触=灰 `#94A3B8` → 初学=橙 `#F59E0B` → 熟悉=蓝 `#3B82F6` → 精通=绿 `#10B981` → 贯通=紫 `#8B5CF6`。雷达、热力图、章节节点、薄弱点卡均使用同一色阶。
- **进度可视化**：能力雷达（五维）+ 章节×知识点热力图 + 章节节点进度环，帮用户一眼看出“强在哪、卡在哪”。
- **克制不干扰阅读**：阅读区以原文为主；学情、推荐、小结一律用可折叠 / 可关闭的浮层与横幅，不遮挡正文；强调色只用于关键 CTA 与门控状态，避免满屏彩色。

### 6. 可访问性与本地化

- **中文为主**：界面、解析、反馈均为中文；“TOP-N”“费曼”等术语首次出现给中文解释。
- **术语高亮可点击**：原文术语高亮（沿用术语色）可直接点击，弹出术语卡（释义 + 溯源），高亮含义不仅靠颜色，辅以下划线/图标区分。
- **移动端优先**：单列布局、大号触控按钮、主 CTA 置于底部拇指可达区，会话与小结浮层从底部唤起，符合单手操作习惯。
- **无障碍**：支持字号调节与足够对比度；错误/锁定等状态除颜色外配文字标签与图标，保证色觉障碍用户可辨。
